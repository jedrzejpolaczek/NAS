# Dataset Types:
Different types of datasets can pose unique challenges and can influence the effectiveness of different optimization algorithms. For example, imbalanced datasets might require specific sampling techniques or cost-sensitive learning, while large datasets might require more efficient, scalable optimization algorithms.

| Dataset Type                | Description                                                                                                 | Examples                                                                                       |
|-----------------------------|-------------------------------------------------------------------------------------------------------------|------------------------------------------------------------------------------------------------|
| Tabular or Structured Data  | This is the most common form of data, where each record has the same set of features.                       | Iris Dataset, Titanic Dataset                                                                  |
| Time-Series Data            | This type of data is collected over time, like stock prices or weather data. The data points are typically dependent on previous ones. | Stock Prices (Yahoo Finance), Weather Data (NOAA)                                              |
| Unstructured Data           | This includes data like text documents, images, audio files, or videos. These data types typically require additional preprocessing to extract features. | IMDb Movie Reviews, CIFAR-10 (images)                                                          |
| Categorical Data            | This data has a fixed number of discrete values or categories. It includes both nominal data (with no order implied, e.g., color) and ordinal data (with a specific order, e.g., ratings). | Titanic Dataset (survival, class), UCI Adult Dataset                                           |
| Numerical or Continuous Data| This data includes any values that can be measured on a numerical scale, like height, weight, or temperature. | Boston Housing Dataset, Wine Quality Dataset                                                   |
| Binary Data                 | This is a special type of categorical data with only two categories, like true/false or 0/1.                | Breast Cancer Wisconsin Dataset (malignant/benign), Spam Email Dataset (spam/ham)              |
| Sequential Data             | This data has an inherent order, like a series of events in a log file or a sequence of words in a sentence. | Penn Treebank (NLP), Sequential MNIST                                                          |
| Image Data                  | This includes any data in image format, often used in computer vision tasks.                                | CIFAR-10, MNIST                                                                                |
| Text Data                   | This includes any data in text format, often used in natural language processing tasks.                     | IMDb Movie Reviews, 20 Newsgroups                                                              |
| Spatial or Geographical Data| This data includes location-based data, like latitude/longitude or any data tied to geographical or spatial coordinates. | Google Maps Data, NYC Taxi Trip Data                                                           |
| Graph or Network Data       | This includes data about relationships between entities, like social network data or web page links.        | Facebook Social Network Data, Citation Networks (Cora, PubMed)                                 |
| Audio Data                  | This includes data in audio format, often used in speech recognition or sound classification tasks.         | LibriSpeech Dataset, UrbanSound8K                                                              |
| Video Data                  | This includes data in video format, often used in tasks like activity recognition or object detection in videos. | UCF101 Action Recognition Dataset, YouTube-8M                                                  |
| Multimodal Data             | This data includes multiple types of data for each instance, like an article with text and images.          | MS COCO (text and images), Visual Genome (images and region descriptions)                      |
| Multi-label Data            | This data includes multiple labels or outputs for each instance, like a movie that belongs to multiple genres. | Pascal VOC, MovieLens (multiple genres)                                                        |
| Imbalanced Data             | This data includes a target variable with unequal representation of classes.                               | Credit Card Fraud Detection, Rare Event Detection Datasets                                     |
| Multi-dimensional Data      | This data includes instances with a high number of features or dimensions.                                  | Human Activity Recognition Using Smartphones, Higgs Boson Dataset                              |
| Missing Data                | This is any dataset that has missing or null values for some features.                                      | UCI Adult Dataset, Medical Datasets (with missing patient data)                                |


Each dataset type should be tested in 3 variations:
- **Small Datasets:** Important to test if the optimization algorithm works well with limited data and avoids overfitting.
- **Medium Datasets:** Helpful to evaluate the optimization algorithm's performance on a standard size of data.
- **Large Datasets:** Necessary to ensure the algorithm scales well and remains efficient with a large volume of data.

Definition of what is small, medium and big datasets are in architecture.
